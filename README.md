### 🚀 About

Finishing a technical program focused on connected/industrial systems — but honestly, most of what I build happens outside of class.

I like picking a problem, learning whatever it takes, and shipping something that actually works. Lately that's meant self-hosted web apps, a full custom game built inside Minecraft, and getting my hands dirty with hardware and 3D printing on the side.
